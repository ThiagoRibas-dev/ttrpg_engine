# Turn 278 — User

>1. Exact strength comparison within a type

There's no "special +1B". Boon and Bane dice are simple quantity of dice. The resolution of the effect these Boons and Banes have on the pool (Ie. die step-down).

>2. Same source versus different sources
Two sources that have the same name, are the same source. Two classes that have an ability called Rage that give an Enhancement type Boon to the damage Die is the same effect no matter which Class, Feat, Equipment gives the character that ability, for example. It's always a first order check so to speak.

Are two identical spells cast by different casters separate sources? If the spells have the same name. No.
Are two identical auras from different creatures separate sources? If the auras are identical, no.
Are two different Feats from the same Class separate sources? Yes.
Are two different effects from the same item separate sources? Yes. An amulet can't give you a +1 Boon and another +1 Boon to Strength. It can give you a +2 Boon.
Is a spell’s repeated effect the same source if cast on different targets? Yes. Not that that scenario means anything since the same effect is not being applied to the same entity.

4. Bane interaction with the Competency Floor

We had specified. Banes don't have a rule regarding the floor directly and specifically because the floor changes by way of the number of dice being lowered. If there was another mechanic that lowered the number of die, that would also change the floor.

5. Boons and Banes with Automatic Successes

Can a Bane remove or suppress an Automatic Success? No.
Can a Boon grant an Automatic Success? No.
Can a single effect grant both a Boon and an Automatic Success? Yes.
Are Automatic Successes applied before or after Bane resolution? Boons and Banes resolve to decide the size of the pool. Automatic successes are resolved when the pool is rolled (including boons and banes). Different things that work in different moments.
Can a character have more Automatic Successes than Required Successes? As far as the base rules framework, yes. Not sure if any content will do that.
Do Automatic Successes function in opposed contests? Good question. Didn't think of that one. Let's say yes.

6. Boons and Banes with Required Successes

Does a Bane remove a die that would otherwise have contributed a success? As mentioned before, Bane removes a die from the bool before it's rolled instead of after.
Can a Bane reduce a pool below the number of Required Successes? Oh yeah. DC 4 (2) and you only have a single d8? Tough luck.
Can a Bane-induced Die Step-Down change the number of available successes? I don't think this question makes sense.
Can a typed effect directly alter Required Successes, or does that require a Permission? The base rules framework will permit that but have no actual effects like that. The specific effect that might do that will be the purview of the content.

7. Boons and Banes in opposed tiebreaks

Whether Boon dice participate in secondary comparisons. Not sure what a "secondary comparison" means. But a Boon adds dice to the dice pool, if that pool is rolled with that boon, then it's participating.
Whether the final reduced pool is sorted normally. Yes.
Whether a Bane-induced Die Step-Down affects only face size or also tiebreak priority. It changes the dice pool before rolling and nothing else. All other effects during or after rolling are the same as they would be normally as if the reduces, stepped-down pool is the normal pool.
Whether Automatic Successes are always excluded from tiebreaking. The side with the most automatic successes win before any dice is rolled. If both sides have the same number of automatic successes (likely 1), then the dice are rolled and the usual rules apply.

8. Pools beyond the normal 5dX range

Whether typed Boons can generate pools above 5dX. Let's not cap Boons but cap the floor at one less than the die size (3d4, 5d6, 7d8, etc). If that level of stacking will happen will depend on how we balance the content of the system.
Whether excess dice remain ordinary dice. Yes.
Whether high-tier content should convert extra dice into Automatic Successes. No. High tier content should combination of Boon dice and automatic successes.
Whether multiple content sources can each extend pool volume. Yes. The point of having the different types is stacking these on the same pool.
Whether the same-type stacking rule applies to extra-dice effects. Extra-dice as in Boons? Yes. That's the whole point. Or did we make a distinction somewhere between these?
Whether a 10d12 pool is theoretically legal or only exceptional. As per the first bullet point, we'll cap the floor at die-size - 1, so it would be legal, with the floor being 11.

9. Effects that alter type rules

Whether any effect can explicitly override normal type stacking. We'll operate on a "specific rules override general rules", so in theory yes. But we have no plans of making such content, although it could be a neat tool to use for Mythic content down the line I suppose.
Whether “stacks with another effect” is a Requirement or Permission. That would be a Permission.
Whether a special effect can allow two same-type Boons to stack. Sure. The base rules framework won't prevent that.
Whether such exceptions require a unique Trait. No. It'll be the purview of the content designers add specific clauses to that effect. We don't plan on making any such content at this point.
