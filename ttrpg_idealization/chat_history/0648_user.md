# Turn 648 — User

Class-table standard:

Use the D&D 3.5e reference structure:

- Descriptive text.
- Class table.
- Feature-by-feature description.

Universal class document sections:

- Class Name.
- Class Description.
- Class Requirements (optional).
- Class Skills.
- Level-by-level Class Table.
- Description of Individual Abilities.

Level-by-level table headers:

Level | Vitality | Stamina | Essence | Fortitude | Reflexes | Willpower | Spell Slot (Optional) | Other Specific Progression (Optional) | Special

Good, Medium, and Bad are design-reference progressions, not player-facing labels. Each class-table level is a self-contained investment showing exactly what that class level grants.
