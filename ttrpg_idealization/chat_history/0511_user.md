# Turn 511 — User

I like it, but the number of Combat Maneuvers is growing rapidly, so I'd merge a couple of them I think : 

```

Social Skill	Maneuver / Activity	General combat role

Leadership or Diplomacy	Rally	Coordinate, encourage, direct, or steady allies

Intimidation	Intimidate	Frighten, pressure, or force hesitation

Deception or Performance	Taunt	Bait, mislead, or create a tactical opening

```

I'm not sure about Read Oponent, since that might complicate things by, for example, "locking" a course of action for an actor, which could be a Player Character.

We should probably create a Maneuver Activity to codify using Lore and Knowledge Skills to figure our a creature's Weaknesses, Attributes, etc.

Maybe we could create an Assess Maneuver Activity that can use Ingisht, Knowledge, or Lore depending, with Insight being more general than Knowledge which is more general than Lore.
