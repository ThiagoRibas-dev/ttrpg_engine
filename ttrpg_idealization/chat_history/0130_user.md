# Turn 130 — User

It essentially works the same as SotDL's Power, but only controls the character's position on the Spell Slot table. The good mediocre and bad "tracks" are not actual in game constructs, but design guidelines.

So a Wizard advances spellcasting (+1 "power") every level, a Paladin does so every other level, an Eldritch Knight does it once every 3 levels, etc.
