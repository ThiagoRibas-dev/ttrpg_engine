OD-001A — Shared Spell-Slot Progression

Remaining: design and calibrate the Mediocre and Bad reference tables.

We don't actually need these tables, since we just move up the Reference Spellcasting (Slot) Progression table at each level the class says it advances the Spellcasting Slot Progression. As we defined before, the class tables will define level by level what they gain, including this advancement Spellcasting Slot Progression advancement.

Maybe we should come up with a better name than "Spellcasting Slot Progression, akin to SotDL's Power stat, but without it being an acual stat you keep track of.

We have full casters advance every level, mediocre casters advance every other level, and bad casters advance once every 4 levels, since that creates a nice numeric equilibrium where a full caster gets 9th level spell slots, a mediocre caster gets 6th, and a bad caster gets 3rd.
