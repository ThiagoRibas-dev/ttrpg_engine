# AI Designer — 0728

Explained that “Permission” is not a standard player-facing TTRPG term and can sound legalistic or software-oriented. Recommended avoiding it as a general framework noun: use Access for eligibility to content, Requirement for a use condition, Effect for what happens, and explicit exception / specific rule for departures from baseline. In player-facing text, prefer direct “you can / cannot” wording. No terminology was changed pending user approval.
