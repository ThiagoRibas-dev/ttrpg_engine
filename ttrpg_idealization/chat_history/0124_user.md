Does a character's highest Tradition Rank limit the highest slot they can use?

No. As we discussed before, Class controls Spell Slot progression, Tradition gates spell access and controls spell scaling.

So it would be theoretically possible for a character to have only first level spells and yet have a full slot progression it can use to cast those first level spells.

In practice, class design would prevent that scenario, but the underlying framework would perit that.

How does Mythic advancement expand or transform the shared slot pool?

Mythic advancement doesn't add new spell slots, but it does give the player access to Epic Traditions and Spells that a player can cast with its normal Spell Slots.
