# Reference and Inspiration System Index

**Status:** Research navigation index; non-canonical.  
**Purpose:** List every named game, engine, system family, or internal case study currently catalogued as a reference, comparison target, inspiration, compatibility target, or process reference in the project’s active research artifacts.

## How to Read This Index

```text
A system appearing here does not make any of its rules canonical.

Canonical rules override this index.

“Use” records the narrow reason the system is consulted.
It does not authorize wholesale import.
```

### Reference roles

| Role | Meaning |
|---|---|
| **Primary compatibility anchor** | A major source for conversion testing and content compatibility. |
| **Primary / secondary design anchor** | A major recurring design comparison. |
| **Focused mechanical reference** | Consulted for a particular subsystem or design question. |
| **Broad architecture reference** | Included in the wide 23-system architecture matrix. |
| **Process reference** | Consulted for design / playtest process, not for direct mechanics. |
| **Internal case study** | A project-specific or supplied design artifact, not an external published game. |
