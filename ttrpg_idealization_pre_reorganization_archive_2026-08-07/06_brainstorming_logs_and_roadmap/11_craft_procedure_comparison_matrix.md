# Craft Procedure Comparison Matrix — D&D 3.5e, PF2e, Forbidden Lands, and Project Proposal

**Status:** Research and design draft; non-canonical.  
**Purpose:** Compare three crafting procedure models against the project’s established Activity, Craft specialty, Durability, and repair framework. This document proposes no rule by itself.

## Systems Compared

| System | Why included |
|---|---|
| D&D 3.5e | Main compatibility anchor; detailed Craft specialties, tools, materials, daily/weekly progress, and repair |
| Pathfinder 2e | Structured modern activity model; explicit tools, formulas, setup, downtime, item levels, and repair |
| Forbidden Lands | Much simpler procedure; discrete Craft/repair roll, tools/materials/talents, and item reliability |
| Project proposal | A simplified hybrid compatible with fixed Difficulty Vectors, Craft specialty ranks, typed Boons/Banes, project scope, and minimal table arithmetic |

## 1. Craft Specialty Requirement

| Question | D&D 3.5e | PF2e | Forbidden Lands | Project proposal |
|---|---|---|---|---|
| Is a specialty required? | Each Craft is a separate skill; the appropriate Craft is required for the item | One Crafting skill; formula, proficiency, and item requirements gate work | Crafting skill plus a specific talent for advanced items | Recipe states the required `Craft — X` specialty and minimum Rank; simple improvised work may explicitly waive specialty requirement |
| Can general/improvised work occur? | GM may permit a reasonable Craft; improvised tools impose penalty | GM adjudication; Crafting covers broad categories | Improvised/simple work can be easier; advanced items require talent | Yes, only when the Activity explicitly allows improvised work; output is temporary, limited, or fiction-defined |
| Compatibility lesson | Preserve discrete professions | Preserve clear gates | Preserve simple exceptions | Separate Craft specialties; let recipes define gates rather than inventing a universal general Craft rank |

## 2. Recipe / Project Entry

| Field | D&D 3.5e | PF2e | Forbidden Lands | Project proposal |
|---|---|---|---|---|
| Required rank | Usually implicit in skill investment, feat, or item requirements | Proficiency/item level may gate access | Talent gates advanced items | Explicit minimum Craft Rank |
| Plan / formula | Often implicit; special items may require a formula | Formula is often required or reduces setup time | Recipe/requirements usually item-specific | Recipe/project explicitly states plan, recipe, formula, blueprint, or Permission if needed |
| Materials | Usually one-third item price | At least half price, then remaining materials or downtime | Raw materials and sometimes special tools | Ordinary abstract units; exceptional named components |
| Tools / workshop | Artisan tools; masterwork tools improve check | Required toolkit; some work uses facilities | Tools and sometimes special tools | Required / Improvised / Helpful / Specialized tool status; workshop tier |
| Time | Daily or weekly numerical progress | Setup plus downtime days | Usually one discrete Craft effort plus stated time | Recipe/project-defined interval; no price-progress arithmetic |
| Resolution | Craft check vs DC; progress arithmetic | Craft check vs level-based DC and degrees | Crafting roll; successes affect result | Difficulty Vector or stated project check |
| Output / failure | Item when progress reaches price; failure delays or loses materials on severe failure | Item on success; failure salvages; critical failure loses some materials | Item/repair result based on successes | Recipe/project explicitly states output, batch, delay, material loss, quality, or other result |

## 3. Craft Families

| Family | D&D 3.5e | PF2e | Forbidden Lands | Project proposal |
|---|---|---|---|---|
| Improvised work | GM adjudication; tools affect check | GM adjudication | Simple field crafting is common | Explicitly permitted only by the Activity; temporary/limited output by default |
| Standard item | Craft over days/weeks via progress | Formula + setup + Craft/downtime | One discrete Craft procedure after requirements | One check after stated interval; recipe defines output and failure |
| Batch production | No special core batch abstraction | Consumables can be batch-crafted | Successes may improve output/durability | Recipe states batch size; one consequential check applies to batch |
| Major project | No universal project loop; GM procedure | Long downtime / campaign systems | Item-specific or campaign procedure | Project Downtime Activity with stated intervals and only a few consequential checks |
| Repair | Same Craft DC as creation generally | Discrete Repair Activity | Discrete repair roll | Simple Repair for non-Broken items; Broken Repair per recipe |

## 4. Workshop Tiers

| Tier / concept | D&D 3.5e | PF2e | Forbidden Lands | Project proposal |
|---|---|---|---|---|
| Improvised | Improvised tools impose penalty | GM adjudication | Field tools and materials matter | Only Activities explicitly permitting improvised work; may impose Circumstance Bane |
| Portable | Artisan’s tools | Toolkits such as repair/healer’s kits | Travel tools | Supports field work, simple repair, and portable recipes |
| Standard | Artisan shop/lab implied | Work area as needed | Workshop/tools as item requirement | Forge, kitchen, alchemy lab, tailoring bench, or equivalent; recipe requirement for ordinary professional work |
| Specialized | Alchemy lab, special facilities | Formula, facility, item-level access, special materials | Advanced item tools/talent | Shipyard, siege forge, gem studio, magical workshop; required for complex, masterwork, unusual-material, or project-scale work |
| Recommendation | — | — | — | Workshops normally act as Requirements/Permissions; only specific workspaces grant stated Enhancement Boons, time reduction, or output benefits |

## 5. Hybrid Materials

| Material model | D&D 3.5e | PF2e | Forbidden Lands | Project proposal |
|---|---|---|---|---|
| Ordinary materials | Currency fraction of item price | Currency/material value fraction | Named raw materials/resources | Abstract material units: metal, timber, leather, cloth, reagents, food supplies |
| Exceptional materials | Special material rules and item components | Precious materials, rare formulas, rare components | Special resources and advanced requirements | Named: adamantine, dragon scale, rare herb, venom gland, celestial feather, etc. |
| Magical materials | Separate magic-item requirements | Formula, item rarity, magical requirements | Setting/item-specific | Named component, ritual, formula, Tradition, or specialized workshop Requirement |
| Recommendation | — | — | — | Hybrid: abstract ordinary materials; named exceptional/magical components |

## 6. Project Resolution

| Question | D&D 3.5e | PF2e | Forbidden Lands | Project proposal |
|---|---|---|---|---|
| Repeated rolls? | Yes, daily/weekly progress checks | Setup check plus optional downtime days | Usually one discrete roll | No routine repeated interval rolls |
| Success levels? | Numeric result determines progress | Degree of success changes material-time result | Extra successes improve output/reliability | No universal success-level rule currently exists |
| Stages? | Usually not formal | Some complex tasks use separate activities | Item-specific | Project may explicitly define stages only when it has genuinely separate tasks |
| Long project abstraction | None in core Craft | Downtime and campaign systems | Campaign/item-specific | Project Downtime Activity: stated intervals, then only stated consequential check/checks |
| Recommendation | — | — | — | Project-defined outcomes and/or explicit stages; do not create universal Craft degrees until core resolution needs them elsewhere |

## 7. Output and Failure

| Outcome | D&D 3.5e | PF2e | Forbidden Lands | Project proposal |
|---|---|---|---|---|
| Success | Accumulate enough progress to finish item | Complete, pay remainder, or use downtime | Produce/repair item; extra successes may improve result | Stated output or batch after stated interval |
| Ordinary failure | No progress | Salvage materials, restart | Usually no item/repair result | Default: no progress beyond time spent unless recipe says otherwise |
| Severe failure | Lose part of materials | Lose part of materials | May damage gear / worsen reliability | Recipe/project may state material loss, exposure, delay, reduced output, or escalation |
| Quality | Masterwork is separate component/check | Item level/formula/material systems | Extra successes can improve item | Recipe/project may state quality tier, expanded output, reduced time, or other explicit outcome |
| Repair failure | Repair generally uses creation DC | Critical failure can damage item | Repair can worsen/destroy reliability | Recipe or repair procedure states failure; no universal destructive failure rule |

## 8. Recommended Project Baseline

```text
Improvised Work:
  Explicit Activity permission.
  Usually temporary or limited output.

Standard Recipe / Item:
  Relevant Craft specialty, Rank, materials, tools,
  workshop tier, and stated interval.
  One consequential check.

Project Downtime Activity:
  Stated intervals, requirements, batch/project output,
  and only a few consequential checks.

Materials:
  Ordinary abstract units.
  Exceptional named components.

Workshops:
  Improvised / Portable / Standard / Specialized.
  Requirement/Permission first; specific benefits only when stated.

Repair:
  Simple Repair for functional items.
  Recipe-driven Broken Repair for nonfunctional items.

Failure:
  Project/recipe-specific; no universal complication table.
```

## 9. Decisions Remaining

1. Adopt the Improvised / Standard / Project Craft family distinction?
2. Adopt the four workshop tiers?
3. Adopt hybrid material tracking?
4. Adopt project-defined outcomes and explicit stages rather than a universal Craft success-level rule?
5. Define a standard vocabulary for recipe/project downtime intervals.
6. Decide whether recipes require a plan/formula by default or only for complex/specialized work.
