# Pool-Size Floors: Canonical Change Impact Report

**Purpose:** Identify the changes required to record the approved shift from Competency-defined Floors to pool-size-defined Floors.  
**Scope:** `03_core_baseline_system/` and directly related tracking artifacts.  
**Changes made:** Decision recorded in `DEC-062`, the Outstanding Definitions Index, and the Phase 1 Checklist. Canonical procedural edits remain a separate implementation task.

## Approved Framework Change

The new model is:

```text
Competency Rank → Baseline Dice Pool Size
Final Dice Pool Size → Floor
```

Baseline Competency progression:

| Competency Rank | Baseline Pool | Base Floor |
|---|---:|---:|
| Untrained | 1dX | 1 |
| Trained | 2dX | 2 |
| Expert | 3dX | 3 |
| Master | 4dX | 4 |
| Legendary | 5dX | 5 |

Boons and Banes modify final pool volume. The Floor is recalculated from the final number of dice.

The already-canonical die-size cap remains:

> **Final Floor cannot exceed one less than the final die size.**

Examples:

```text
5d8 → Floor 5
5d4 → Floor 3, because d4 − 1 = 3
10d12 → Floor 10, because d12 − 1 = 11
```

A Bane-induced Die Step-Down changes the die size. A Bane removing a die changes the pool-size Floor. These are separate effects.

## Paired Defenses

Paired defenses use the total number of dice in the paired pool to determine the Floor.

Example:

```text
Reflexes:
  1dDEX + 1dINT keep highest
  Total pool volume: 2 dice
  Floor: 2, subject to the final die-size cap
```

If the Attributes have different die sizes, the pool remains mixed-size, but the Floor is based on the total number of dice, not on the number of dice of each size.

# Required Canonical File Updates

## 1. `03_core_baseline_system/00_baseline_framework_glossary.md`

### Update `Competency Floor`

Replace the current definition, which describes the Floor as imposed by Competency Rank, with:

> **Competency Floor:** The minimum result generated by the final Dice Pool. Competency Rank establishes the baseline pool size; Boons and Banes modify final pool volume; the Floor is recalculated from the final number of dice and cannot exceed one less than the final die size.

### Update `Natural Dice Pool`

Clarify that the Natural Dice Pool includes the baseline pool volume produced by Competency Rank.

### Update `Enhanced Dice Pool`

Clarify that the Enhanced Dice Pool’s final number of dice determines the effective Floor.

### Update `Bane`

Clarify that removing a die lowers the Floor through the ordinary pool-size rule, while a Bane-induced Die Step-Down changes die size and may therefore lower the Floor cap.

## 2. `03_core_baseline_system/01_resolution_engine.md`

### Update base pool construction

Replace the existing Competency table:

```text
Untrained: 2 dice, Floor 0
Trained: 3 dice, Floor 3
Expert: 3 dice, Floor 5
Master: 4 dice, Floor 7
Legendary: 5 dice, Floor 9
```

with:

```text
Untrained: 1dX, Floor 1
Trained: 2dX, Floor 2
Expert: 3dX, Floor 3
Master: 4dX, Floor 4
Legendary: 5dX, Floor 5
```

The table should identify the Floor as derived from final pool size rather than as an independent Competency Rank output.

### Replace Floor procedure

The current section says Competency Rank establishes a Floor. It should instead state:

1. Build the Natural Dice Pool.
2. Apply ordinary pool-volume effects.
3. Apply Die Step-Ups and Die Step-Downs.
4. Resolve Boon/Bane cancellation and apply final pool-volume changes.
5. Set the Floor equal to the final number of dice.
6. Cap the Floor at one less than the final die size.
7. Apply Automatic Successes and resolve the roll.

### Update Bane examples

Examples should show both effects:

```text
4d8, Floor 4
+1 Bane → 3d8, Floor 3

1d8, Floor 1
+1 Bane → 1d6, Floor 1
```

The second result does not reduce pool volume below one; it changes the die size only.

### Update oversized-pool rule

The final Floor cap must remain explicit for pools beyond the natural `5dX` range:

```text
7d8 → Floor 7
10d12 → Floor 10
```

The floor cap is not a separate lookup table; it is the smaller of:

```text
Final Dice Count
Final Die Size − 1
```

