# Deprecated Skill Architecture

The files in this directory are historical skill-system designs. They are retained for conversion work, comparison, and design provenance.

The former 65-skill Pulverized Master Skill Matrix has been superseded by `DEC-049`, the canonical Domain-and-Activity Skill Architecture.

Canonical replacement:

`../03_core_baseline_system/13_building_block_domains_and_master_skill_system.md`

The current architecture uses:

- Eight functional Domains.
- Specific transferable Skills.
- Defined Craft specialties.
- Open-ended Lore specialties.
- Formal Knowledge skills.
- Separate provisional Magic Mastery skills.
- Activities and procedures that select skills by approach.
