# Archive and Deprecated Design Material

This directory contains superseded design documents, previous architectures, and historical discussion artifacts retained for conversion reference and design provenance.

## Status Convention

- **Canonical:** Current rules and procedures. These remain in the active system directories.
- **Discussion:** Brainstorming, comparative analysis, simulations, and decision logs. These inform the design but are not rules by themselves.
- **Archived:** Superseded or deprecated designs retained for reference only.

Archived material must not override canonical rules unless a later decision explicitly restores or revises it.
