# D&D 3.5e Base Class Profiles — Initial Modeling Draft

**Status:** Conversion and content-modeling draft; non-canonical.  
**Scope:** Initial class-chassis comparison for the eleven supplied D&D 3.5e SRD Base Classes. This is not a class compendium and does not establish a progression track, defense rule, spell rule, or Class feature.

## 1. Modeling Premise

A class should use the shared engine’s existing progression vectors rather than recreate D&D 3.5e numerical bonuses:

```text
Vitality track
Stamina track
Essence track
Spell Slot progression
Combat Skill investment and Class combat contributions
Paired defense progression
Skill / Domain investment
Class features and Feats
```

### Combat track interpretation

The **Combat competency** column in the class matrix is not a separate Base Attack Bonus or universal combat progression. It is a modeling shorthand for:

```text
High, medium, or low investment in one or more Combat Mastery Skills;
plus any Class-provided combat dice, Permissions, Feats,
Automatic Successes, or other explicit combat contributions.
```

There is no separate BAB analogue. Strikes use the relevant Combat Mastery Skill and Attribute under the ordinary pool-building framework. A Class expresses martial identity by protecting or accelerating investment in appropriate Combat Mastery Skills and by granting explicit combat features.

### Defense modeling framework

Good, Medium, and Bad Fortitude, Reflexes, and Willpower now use the same Rank cadence as protected Skill progression. A Good defense therefore mirrors full Rank investment in a relevant combat capability. A paired defense uses its highest paired Attribute Die as die size and the class defense Rank as baseline pool volume.

The class assignments in this draft remain conversion proposals until individual Classes are approved.

## 5. Base-Class Identity Tests

The class models must eventually demonstrate the following without relying on D&D-style linear BAB or save bonuses.

| Identity | What must make it distinct |
|---|---|
| Barbarian | High Vitality/Stamina, forceful Weapon Traits, Rage permissions, risk/reward offense |
| Bard | Social Activities, Rallied support, performance-tagged content, flexible spell access |
| Cleric | Tradition access, Fortitude/Willpower resilience, divine support, Channel/Turn-style abilities |
| Druid | Primal Tradition, environmental permissions, transformation/companion framework |
| Fighter | Combat Skill breadth, Feat density, Deflect/Interpose specialization, weapon versatility |
| Monk | Martial Arts, Good all defenses, Stamina/Essence discipline, unarmed mobility |
| Paladin | Heavy armor, Deflect/Interpose, divine Tradition, protective and smite content |
| Ranger | Good Reflexes, Archery/mobility, terrain and prey permissions, limited magic |
| Rogue | Good Reflexes, Finesse, Piercing access, Assess/stealth, precision damage later |
| Sorcerer | High Essence/slots, innate casting identity, narrow but potent Tradition access |
| Wizard | High Essence/slots, preparation breadth, Knowledge/Assess, ritual and metamagic depth |

## 6. Class Modeling Questions

1. Should class defense tracks use only **Good** and **Bad**, as D&D 3.5e saves do, or also a Medium track for greater flexibility?
2. What exact pool contribution does a Good defense grant at Levels 1–20, and how does it mirror full Combat Mastery investment?
3. How do Good, Medium, and Bad Combat Skill investment / Class contribution profiles map to Competency Rank, Dice Pool volume, and explicit Class features under current canon?
4. Is Bard spellcasting Medium, or should it use a distinct sixth-circle progression?
5. Are Paladin and Ranger both Medium Slot progression, or do they need different acquisition and preparation identities rather than different slot tables?
6. Does Monk have Good Essence from Level 1, or does its internal supernatural reserve begin later through class features?
7. Which class identities are best expressed through baseline progression and which should be reserved for Class features, Feats, Traditions, and equipment Permissions?
8. How should multiclassing combine class defense track contributions without making early dips disproportionately efficient?
