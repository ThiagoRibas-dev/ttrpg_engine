# Class Modeling Workspace

**Status:** Conversion and content-modeling workspace; non-canonical.

This directory models D&D 3.5e SRD Base Classes against the project’s current framework. It is intended to test advancement vectors, class identity, compatibility conversion, and future content architecture. No class profile, progression assignment, defense track, or ability in this directory is a player-facing rule until separately approved and placed in a canonical owner.

## Contents

- `dnd_3_5e_srd_sources/` — supplied D&D 3.5e SRD Base Class source documents.
- `01_dnd_3_5e_base_class_profiles_draft.md` — initial chassis matrix and open modeling questions.
- `02_triel_fitheaben_level_20_provisional_conversion.md` — a non-canonical conversion exercise for a complex Level 20 Cleric / divine-martial multiclass character; tests Skill Investments, Class Skill-list access, resource tracks, protected progression, and bounded-equipment translation.

## Modeling Boundary

The workspace may propose how a source class maps to:

```text
Vitality
Stamina
Essence
Spell Slot progression
Combat competency
Fortitude / Reflexes / Willpower progression
Skills and Domains
Class features and Feats
```

It must distinguish:

```text
Source fact
  What D&D 3.5e does.

Conversion hypothesis
  How that source fact might map into this project.

Canonical decision
  An explicitly approved rule recorded elsewhere.
```
- `../../02_comparative_system_analysis/34_divine_domain_to_tradition_skill_proposal.md` — non-canonical proposal mapping legacy Divine Domains into a bounded Spell Tradition Skill catalogue.
- `03_triel_fitheaben_class_skill_rebuild.md` — Revision 2 of Triel’s conversion: source-driven Class Skills, Domain Tradition access, 25 baseline Investments, and 17 Magic Mastery-only Investment audit.
- `04_triel_fitheaben_level_by_level_advancement_matrix.md` — one 20-row non-canonical simulation combining Triel’s Class levels, Investments, Attributes, Spell Slot Advancements, and provisional resource totals.
- `05_triel_fitheaben_level_by_level_advancement_matrix_revision_2.md` — corrected 20-row Triel simulation using DEC-100: one Magic Mastery-only Investment per Slot Advancement plus Domain Tradition Grants.
- `06_triel_fitheaben_feature_conversion_inventory.md` — non-canonical feature-by-feature inventory mapping Triel’s source abilities to current framework anchors, dependency status, and future cost questions.
