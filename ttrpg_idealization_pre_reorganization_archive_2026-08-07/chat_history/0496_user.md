## Dazed — Head Wound

I'd change it slightly, since it makes no sense to increase action cost for an Activity you can't use.

```

> **Dazed**  

> A Dazed creature cannot spend Essence. It also pays **+1 Action** to perform Activities with the Concentrate Tag.

>

> If the increased cost exceeds the creature’s Actions remaining for the turn, it cannot perform that Activity.

```

## Fatigued — Chest Wound

```

> **Fatigued**

> A Fatigued creature cannot spend Stamina.

```

## Nauseated — Abdomen Wound

Text is good.

## Impaired — Arm Wound

I'd tweak the text to not create a new rules term:

```

> **Impaired**  

> When performing a Strike Activity or an Activity with the Manipulate Tag, an Impaired creature must roll `1d10`. On a result of **1–2** (20%), the Activity fails. Its Actions are spent, but other resource costs for that Activity are not spent.

>

> A creature has only one Impaired condition regardless of how many arms it has. Additional arm Wounds do not stack Impaired.

```

We'll borrow the Manipulate Tag from PF2e to describe Activities that involve manipulating things (taking spell components, handling a shield, using a potion, etc). That way we don't have to hardcode everything in the rules text itself.

## Flat-Footed — Leg Wound

I'd tweak it slightly to be more generic and easy to understand :

```

> **Flat-Footed**  

> A Flat-Footed creature cannot use Reflexes. It counts as flanked against physical attackers.

>

> Ay Activity that spends a creature's Movement costs **+1 Action**.

>

> If the increased cost exceeds the creature’s Actions remaining for the turn, it cannot begin that Activity.

```

We have some new vocabulary in Action, Activity, Tag, etc. A lot of ideas borrowed from PF 2e (which are evolutions of ideas from D&amp;D 3.5e).

Feel free to agree or criticize these.
