# Turn 45 — User

Alright. We'll do some more fundamental changes.

Competency Ranks: The definition that it "measure specific player investment in one of the 5 Action Mastery Domains" is correct, but each domain should not be a single thing the player can invest in, since that would be way too abstracted. Walking silently and hiding from view should be two different things, as should be knowing about dragons vs knowing about bears, as well as convincing through intimidation vs lying vs being diplomatic, etc.

Action Economy & Turn Structure: Let's call the distance tiers 0 Close, 1 Near, 2 Medium, 4 Far, 4 Distant.

In-World Resources & Daily Pacing: I like Stamina and Focus, but we will still have a "Vancian" casting system, so casting a spell doesn't necessarily need focus by default, only for other secondary reasons.

Durability Slots: How would this compare to D&D 3.5e's item HP, hardness, and Sundering?

Encumbrance Slots: We should base this on both STR and CON, much like vitality.

Hit Location & Anatomical Wound Severance: Wouldn't a crit being Damage rolled Max Face mean that higher dice have a lower change of critting? Maybe we could use D&D 3.5e as inspiration. Weapons have a crit profile (% chance for crit) and the player rolls a d100 with their dice pool to see if they crit.

Wounds should only happen on a Crit, although normal hits could have minor disrupting effects that can be quickly resolved with the right Class Abilities, Feats, etc.

A player should be able to force a wound (and its effect) by using a Called Shot maneuver at some cost.

Class Advancement Tracks & 20-Level Progression: Write a progression matrix showing the advancement of each track (good, okay, bad).
