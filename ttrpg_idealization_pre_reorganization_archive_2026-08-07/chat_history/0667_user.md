# Turn 667 — User

Rejected the partial Skill Investment model as misaligned with Competency Rank gates. Proposed a semi-granular model: the character invests in N Skills every few levels, each investment increases a chosen Skill by one Rank up to the maximum Rank available at that Character Level. Example sketch uses 2 investments at Levels 1, 3, 5, 7, 9, 11, 13, 15, 17, and 19, with Rank limits Trained at 1, Veteran at 5, Master at 9, Hero at 13, and Legend at 17. Exact schedule and investment count remain open.
